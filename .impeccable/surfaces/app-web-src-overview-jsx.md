No-code users need to find current work, inspect its real state and enter the
existing plan or tool. The Owner's named-theme world and task-flow-first brief
supply the direction; this is code-led refinement, not a new identity selection.

## Direction contract

THESIS: Make the next real task the visual focus; replace generic illustration
and repeated dashboard boxes with actual records and familiar work lists.

OWN-WORLD: Preserve Dark Modern graphite, the 15 named VS Code palettes, local
Manrope/IBM Plex Thai, Lucide icons, tonal chrome and native form conventions.

STORY: Read task, status and owner; open the plan; inspect recent tasks; enter
Office, reports or notebooks through the existing routes. Empty projects explain
how to begin. No part of Overview starts execution or invents provider activity.

FIRST VIEWPORT: Sidebar and top bar frame the page title. One roomy task surface
puts the actual title left, project context right, and the plan action under task
metadata. Compact exact record totals precede recent work and tools.

FORM: Existing workbench refinement, code-led. The binding brief supplies the
world and task focus; no direction tournament or generated comp was used. Parent
assignment: "Dark Modern default graphite, preserve all15themes" and "one authored
precise focal moment in Overview tied to actual records/task flow".

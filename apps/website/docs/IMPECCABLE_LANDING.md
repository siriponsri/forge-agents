## Real download integration

`SourceDownloads.tsx` reads only same-origin `/downloads/manifest.json`. It
validates schema/product/kind/unsigned flag, a 40-hex source commit, exactly one
Windows and macOS entry, fixed filenames/URLs, positive bytes and 64-hex hashes.
Only then does it expose direct `download` anchors. Until metadata arrives or if
invalid, Home links to package details; the download page gives loading/error
feedback and Retry. No private runtime API is called. No-JavaScript HTML has
explicit direct ZIP links and the manifest. Details explain extraction,
Start/Stop/Restart, Node 24.13+, first-start network dependency installation,
unsigned development/source status, macOS/live/Home NOT_RUN and incomplete
product implementation. GitHub Releases retain their separate existing policy.

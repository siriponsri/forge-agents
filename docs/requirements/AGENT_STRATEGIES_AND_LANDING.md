## Required strategy behavior

| Mode | Actual behavior and acceptance |
| --- | --- |
| Supervisor / Orchestrator–Workers | Main agent decomposes approved work and prompts explicitly approved child sessions through the existing exact-attempt owner. Show parent/child status, decisions and retained commands. |
| Parallel fan-out / fan-in | Start independent approved allocations within existing Workspace/Budget concurrency limits; gather actual terminal results/evidence. No duplicate or conflicting checkout ownership. |
| Router + Specialists | Record the selected specialist and reason against actual scoped roles/capabilities/model catalog. Execute through the existing selected owner; unavailable routes require setup. |
| Generator + Verifier | Execute the approved generator and a separate reviewer/check step; retain reproducible findings and feedback. A verifier's self-report never supplies independent success or Owner approval. |
| Sequential pipeline / DAG | Persist explicit stages/dependencies, reject cycles, and release only eligible stages. Keep deterministic/code-only steps where sufficient and preserve failed/unknown blockers. |
| Independent candidates + selection | Keep candidate work independent, retain rubric/evidence and require explicit supported selection. Display duplicate-work/cost tradeoffs; selection does not auto-merge unreviewed work. |

All modes need Thai-default/English setup, selected-mode explanation, a real
execution/reconcile/Stop path, exact run/attempt associations, and meaningful
tests. Preserve once-only operation identities and unknown/no-redispatch on
lost response, concurrent calls, restart or restore. Reuse canonical T3,
Conversation, Workspace, Goal/Budget and approval owners; do not import a second
turn engine or treat role labels, prompt text or configuration as authority.
Ordinary safety guards, fixed deadlines, account/source fences and scoped
permissions remain mandatory. Missing live accounts are separate from missing
mode implementation. Do not run the example prototype products automatically.

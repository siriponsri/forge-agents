temporary provider boundaries, isolated worktrees, cleanup and recovery. The
Electron-owned browser capability was not installed; that surface remains
fail-closed. Real Codex sessions were intentionally blocked in empty homes, so
generic session mechanics were tested with a local non-model fixture harness.

planner. Integration beyond this adapter requires a later OWNER decision.

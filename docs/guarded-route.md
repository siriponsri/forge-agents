# Bounded native automation

The initial FORGE Guarded route supports reading, proposing and replacing
existing UTF-8 text files up to 64 KiB inside an Owner-approved recipe scope.
It uses the matching private T3/OpenCode adapter and Windows handle-relative
file broker. Shells, arbitrary MCP attachment, delegation, new files and external
writes are unavailable on this route. Ordinary supervised providers retain their
existing setup and execution paths.

In Project settings, select a configured OpenAI-compatible chat API model, open
**Bounded automation**, install the private runtime and check the selected route.
Installation checks use quarantined files and have no model authority. They do
not verify paid account access or model quality. A stored report cannot recreate
the live private check handle. Changed files, account, model, options, policy or
scope require a current check; changed installed generations require restart.

Approve and enable a Proactive recipe with relative paths and read, propose or
workspace-write capabilities. The first version supports a wall-time limit;
non-null token and monetary caps refuse because the native route cannot enforce
them authoritatively. Each occurrence obtains one canonical run, an independent
run/session attestation, the real Context receipt and final-message digest.
Every native phase repeats current authority. File effects and their durable
receipts share the canonical policy/Stop transaction fence. A prompt grants no
tool permission.

Actual adapter events supply running, tools, messages and terminal status to the
existing AG-UI projection. Native weak references retain their strength; FORGE
does not invent an installed-orchestration run ID. Stop revokes private authority
before awaiting transport and interrupts the observed native turn. Missing
acknowledgments or lost process leases retain unknown outcomes without replay.
Metadata restore preserves accepted run identities and effect history and cannot
restore live credentials or leases.

Credential plaintext is resolved privately from the selected project/purpose
vault reference or explicitly named environment variable. It remains in memory
and the private bootstrap pipe. Synchronous phase checks fence encrypted vault
bytes and reject a concurrent writer; credential mutation revokes leases before
the vault operation. No key is persisted in the provider management RPC or run.

Developer verification connects the production application, authenticated Owner
HTTP actions, real installer copy, scheduler, canonical T3 reservation, Context,
native adapter, compiled CLI, actual file broker and AG-UI. The deterministic
loopback model protocol and controlled schedule due time are labelled fixtures.
One test completed four protocol requests, three real effects/receipts and one
canonical run in 83.4 seconds, with successful tool acknowledgments. Related
policy, DPAPI and lifecycle regressions passed. No external account/model-quality
check or home UAT has run. A longer authenticated transport acknowledgment window
and explicit unknown classification are under separate qualification; they do
not enlarge the accepted wall deadline or grant retries.

Research agent component/action/resource qualification and arbitrary native
Memory attachment remain separate unsupported contracts. Local Research CPU/file
trials and the ordinary scoped Memory HTTP transport continue to work.

# Studio fixtures (synthetic)

`synthetic-house-prices.csv` is **synthetic** demo and test data, generated by
`node app/studio/fixtures/synthetic.mjs` (seed 20261126, 200 rows). It is not real
housing data. Prices follow a known linear relation plus seeded noise (see the
header of `synthetic.mjs`), so a later trainer test can check that the relation is
recovered. The Studio smoke test copies it into a temporary project workspace.
